with Property binding you dont need to use interpolation just []="property Name"
 
<img src="{{url}}">

Property binding is much more usefull when you dealing with actual properties and non string values.


Event binding: 
            Event binding allows and Html event to call a method in your Angular Component.
        
(event)="method()"

sayHello() {
  console.log('Hello!');
}

<button (click)='sayHello()'>Click Me</button>
